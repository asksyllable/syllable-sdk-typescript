# ChannelTargetExperimentSummary

The experiment shown next to a channel target.

## Example Usage

```typescript
import { ChannelTargetExperimentSummary } from "syllable-sdk/models/components";

let value: ChannelTargetExperimentSummary = {
  id: 1,
  name: "Shorter greeting",
  status: "stopped",
  weight: 50,
  startedAt: new Date("2026-10-28T16:00:00Z"),
  scheduledStartTime: new Date("2026-11-14T17:00:00Z"),
  scheduledEndTime: new Date("2026-11-29T01:00:00Z"),
};
```
