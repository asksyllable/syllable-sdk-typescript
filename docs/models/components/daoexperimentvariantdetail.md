# DaoExperimentVariantDetail

A variant, with the name of the agent it runs resolved for display.

## Example Usage

```typescript
import { DaoExperimentVariantDetail } from "syllable-sdk/models/components";

let value: DaoExperimentVariantDetail = {
  id: 1,
  name: "b",
  weight: 10,
  isControl: true,
  agentId: 1,
  agentName: "Front desk",
};
```
