# ExperimentCreateRequest

Create an experiment with at least two distinct agents and one control variant.

The control must use the agent linked to the channel target.
Variant weights are positive whole-number percentages that must total 100.

## Example Usage

```typescript
import { ExperimentCreateRequest } from "syllable-sdk/models/components";

let value: ExperimentCreateRequest = {
  name: "Shorter greeting",
  description: "Test whether a shorter greeting reduces call duration.",
  variants: [
    {
      name: "control",
      weight: 50,
      isControl: true,
      agentId: 10,
    },
    {
      name: "short greeting",
      weight: 50,
      agentId: 11,
    },
  ],
  targetId: 7,
};
```
