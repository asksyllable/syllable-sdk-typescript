# CallResultSaveMapping

One field-extraction mapping applied to a call action's tool response.

Example: {"from": "is_valid", "to": "is_valid"}
Example (derived value): {"from": "status == 'valid'", "to": "is_valid"}

## Example Usage

```typescript
import { CallResultSaveMapping } from "syllable-sdk/models/components";

let value: CallResultSaveMapping = {
  from: "is_valid",
  to: "<value>",
};
```
